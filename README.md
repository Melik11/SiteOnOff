# SiteOnOff

Веб-страница для отображения текущего состояния системы (Включено/Выключено) в реальном времени.

## Открыть сайт

Сайт опубликован и доступен по адресу:  
**https://melik11.github.io/SiteOnOff/**

---

## Использование

Статус управляется через URL-параметры. Для изменения состояния добавьте соответствующий параметр в конец ссылки.

### Параметры

| Параметр | Ссылка | Результат |
| :--- | :--- | :--- |
| Включить | `?status=on` | Зелёная плашка **ON** |
| Выключить | `?status=off` | Красная плашка **OFF** |
| Не задано | *(без параметра)* | Серая плашка **«Не задано»** |

### Примеры ссылок

**Включить:**

    https://melik11.github.io/SiteOnOff/?status=on

**Выключить:**

    https://melik11.github.io/SiteOnOff/?status=off

---

## Важная информация

- **Статус привязан к ссылке.** Он не сохраняется на сервере. Каждый пользователь видит состояние, указанное в его собственной адресной строке. Для корректной работы всегда отправляйте полную ссылку с параметром.

- **Формат ввода.** Соблюдайте строгий формат: без пробелов, разрывов строк или дополнительных символов.

- **Кириллица.** Поддерживаются русские значения: `?status=вкл`, `?status=выкл`, `?status=включен`, `?status=выключен`.

- **Обновление страницы.** Если плашка не обновляется после изменения ссылки, проверьте точность написания параметра и выполните жёсткую перезагрузку:
  - **Windows:** `Ctrl + F5`
  - **macOS:** `Cmd + Shift + R`

Для запуска проекта на локальном компьютере:

2. Распакуйте архив.
3. Откройте файл `index.html` двойным кликом в любом современном браузере.
