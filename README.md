# SiteOnOff

Сайт показывает текущее состояние системы (Включено/Выключено) в реальном времени.

## 🌐 Открыть сайт

Сайт уже опубликован и доступен всем по ссылке:
👉 **[https://melik11.github.io/SiteOnOff/](https://melik11.github.io/SiteOnOff/)**

---

## 📌 Как использовать

Для управления статусом системы используйте адресную строку браузера. Просто добавьте в конец ссылки параметр и нажмите **Enter**.

### Параметры:

| Параметр | Ссылка | Результат на экране |
| :--- | :--- | :--- |
| **Включить** | `?status=on` | 🟢 Зелёная плашка **ON** |
| **Выключить** | `?status=off` | 🔴 Красная плашка **OFF** |
| **Не задано** | *(без параметра)* | ⚪ Серая плашка **«Не задано»** |

### Примеры ссылок:

✅ **Включить:**  
`https://melik11.github.io/SiteOnOff/?status=on`

❌ **Выключить:**  
`https://melik11.github.io/SiteOnOff/?status=off`

---

## Важная информация

1. **Статус привязан к ссылке.** Он не сохраняется на сервере. Каждый пользователь видит то, что прописано в его собственной адресной строке. Для корректной демонстрации всегда отправляйте полную ссылку с уже добавленным параметром.
2. **Формат ввода.** Соблюдайте строгий формат: без пробелов, разрывов или дополнительных символов.
3. **Кириллица.** Поддерживаются русские значения: вместо английских можно использовать `?status=вкл` и `?status=выкл`.
4. **Обновление страницы.** Если плашка не обновляется после изменения ссылки, проверьте точность написания параметра и выполните жёсткую перезагрузку страницы:
   - **Windows:** нажмите `Ctrl` + `F5`
   - **macOS:** нажмите `Cmd` + `Shift` + `R`
