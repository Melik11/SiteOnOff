# SiteOnOff
 Сайт показывает состояние на данный момент 

Для управления статусом системы используйте адресную строку браузера. Просто добавьте в конец ссылки на сайт параметр `?status=on` для включения или `?status=off` для выключения, после чего нажмите Enter.

В зависимости от указанного значения на странице мгновенно появится соответствующая плашка: зелёная с надписью **ON** при активации, красная с **OFF** при отключении или серая с пометкой «Не задано», если параметр отсутствует или написан неверно.

Обратите внимание: статус привязан исключительно к ссылке и не сохраняется на сервере. Каждый пользователь видит то, что прописано в его собственной адресной строке, поэтому для корректной демонстрации всегда отправляйте полную ссылку с уже добавленным параметром.

При вводе команды соблюдайте строгий формат: без пробелов, разрывов или дополнительных символов. Корректный вид: `https://ваш-домен/?status=on`. Также поддерживается кириллица: вместо английских значений можно использовать `?status=вкл` и `?status=выкл`.

Если плашка не обновляется после изменения ссылки, проверьте точность написания параметра и выполните жёсткую перезагрузку страницы: нажмите `Ctrl + F5` на Windows или `Cmd + Shift + R` на macOS.
