# SiteOnOff

Веб-сервер для отображения текущего состояния системы (**Включено** / **Выключено**) в реальном времени. Реализован на Python с использованием только встроенных библиотек.

### 1. Требования

- Установленный интерпретатор **Python 3.x**
- Сторонние библиотеки не требуются

### 2. Скачать файл

Скачайте файл `server.py` из репозитория или сохраните его вручную.

### 3. Запустить сервер

Откройте терминал (командную строку), перейдите в папку с файлом и выполните команду:

```bash
python server.py
```

## Использование

Статус управляется через **URL-параметры**. Для изменения состояния добавьте соответствующий параметр в конец ссылки.

### Параметры

| Параметр | Ссылка | Результат |
| :--- | :--- | :--- |
| Включить | `?status=on` | Зелёная плашка **ON** |
| Выключить | `?status=off` | Красная плашка **OFF** |
| Не задано | *(без параметра)* | Серая плашка **«Не задано»** |

### Примеры ссылок

**Включить:**

    https://melik11.github.io/SiteOnOff/?status=on

**Выключить:**

    https://melik11.github.io/SiteOnOff/?status=off
